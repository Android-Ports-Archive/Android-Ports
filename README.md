## 📖 About This Repository

Welcome to the official GitHub archive for **Android Ports**. As Telegram channels can get messy and old posts get lost in the chat history, this repository was created to serve as a clean, permanent, and easily navigable hub for all our ROM releases. 

Here you will find everything from highly customized MIUI and HyperOS ports to experimental builds of Nothing OS, Flyme OS, and bleeding-edge Android versions for the **POCO F1 (`beryllium`)** and **Xiaomi Mi 8 (`dipper`)**.

## ⚠️ Disclaimer
* **Flash at your own risk.** Neither the Android Ports Team, the maintainers, nor GitHub are responsible for bricked devices, dead SD cards, thermonuclear war, or you getting fired because the alarm app failed. 
* Please read the **Bugs & Known Issues** section of *every* ROM page before flashing.
* Always verify if a ROM requires **DFE (Disable Force Encryption)** or a specific custom recovery (TWRP/OrangeFox).
