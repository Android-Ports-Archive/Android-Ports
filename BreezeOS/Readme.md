## 🛠️ Flashing Instructions

> 🛑 **CRITICAL STEP:** **Flashing DFE is mandatory** for this ROM to boot properly. Do not skip this step.

**Standard Clean Flash Process:**
1. Boot into **OrangeFox Recovery** (Highly Recommended).
2. Go to **Wipe** and perform a format (Dalvik, Cache, System, Vendor, Data).
3. **Format Data** (Type `yes`).
4. Flash the **Breeze OS `.zip`** file.
5. Flash the **DFE `.zip`** file immediately after the ROM.
6. Reboot to System.
