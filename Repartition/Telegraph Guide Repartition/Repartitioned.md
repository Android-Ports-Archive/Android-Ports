This partition guide is for the people that's already repartitioned to either 5gb or 7gb .

First thing first to do is that we want to return to the stock partition size of "3gb" ,

Alert : The steps should be followed as it is , Don't attempt the Second Step without completing the first .

To do that the steps is simple

1. First step

There is a .zip file named "AP_Reset_default_partition_Allocation"

And Here is the file : AP_Reset_default_partition_Allocation

Now The Flashing Steps  ( In Twrp or Orange fox )    

Orange fox recovery is recommended 

1.Wipe Everything and format data using yes option 

2.Flash the .zip file included , restart...

3.After restarting Wipe Everything again, And again format using the yes option 

Now we've completed the first step and we've successfully returned to the stock partition size 

Note : Before going to the Next step restart the device again and enter the recovery 

2. Second step

Now this step is simple and similar to the first step .

there is a .zip file named "Ap-ExpandSystem7GB"

And here is the file : Ap-ExpandSystem7GB

Now again The flashing steps ( In Twrp or Orange fox )    

Orange fox recovery is recommended 

1.Wipe Everything and format data using yes option 

2.Flash the .zip file included , restart...

3.After restarting Wipe Everything again, And again format using the yes option


Now Finaly We've completed the repartition process.
