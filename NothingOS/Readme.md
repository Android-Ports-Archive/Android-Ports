## 💡 Important Notes & Audio Fix

* **Missing System Sounds:** Ringing tones and notification sound files are not loaded by default in this build. You must download the required audio files package (linked below) and install them manually.
* **Future Updates:** Don't worry about wiping your phone again—when the team drops fixes for the annoying bugs, you will be able to dirty flash the update right over this one.

## 🐞 Known Bugs & Issues

* ❌ **Bluetooth Audio**
* ❌ **Vibration / Haptics**
* ❌ **Face Unlock**
* ❌ **OTG Support**
* ❌ **Headphone Jack (3.5mm)**
* ⚠️ **CRITICAL DPI BUG:** Changing the display DPI has a slight delay. **You must wait patiently for it to change.** If you interrupt the process, you will cause a bootloop resulting in complete data loss.

## 🛠️ Flashing Instructions

> 🛑 **CRITICAL WARNING:** **Do NOT flash DFE** (Disable Force Encryption) and **Do NOT flash Permissive** zips with this ROM. Doing so will break the boot process.

1. Boot into custom recovery (TWRP/OrangeFox).
2. Format data like normal (Type `yes`).
3. Wipe Cache and Dalvik.
4. Flash the ROM `.zip` file.
5. Reboot to System.
