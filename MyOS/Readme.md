## 🛠️ Flashing Instructions

> 🛑 **CRITICAL STEP:** This is an Alpha/Experimental build. **Flashing DFE A14 is mandatory** for this ROM to boot properly. Do not skip step 4.

**Standard Flash Process:**
1. Boot into **OrangeFox Recovery** (Highly Recommended).
2. Perform standard wipes (Dalvik, Cache, System, Vendor, Data) if you are clean flashing.
3. Flash the ROM `.zip` file.
4. **Flash the DFE A14 `.zip` file** immediately after the ROM.
5. Format Data (Type `yes`).
6. Reboot to System.
