## 🛠️ Installation Instructions

**Clean Flash (Recommended):**
1. Boot into custom recovery.
2. Wipe Data, Cache, and Dalvik.
3. Flash the ROM `.zip` file.
4. Format Data (Type `yes`).
5. Reboot to System.

**Dirty Flash (Updating from previous MindEdition):**
1. Boot into custom recovery.
2. Flash the ROM `.zip` file as usual.
3. Reboot to System.
