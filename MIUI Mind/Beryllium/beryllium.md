## 🛠️ Installation Instructions

> 🛑 **REQUIREMENT:** The latest version of TWRP is heavily recommended for this build. **Clean flash is strictly mandatory.**

**Steps to Flash:**
1. Boot into the latest TWRP recovery.
2. Wipe Data, Cache, and Dalvik.
3. Flash the ROM `.zip` file.
4. Format Data (Type `yes`).
5. Reboot to System.
